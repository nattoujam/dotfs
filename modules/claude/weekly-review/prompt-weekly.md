# 週次レビュー（運用向け）

今回は直近 1 週間の運用レビューです。1 週間は摩擦を拾うには十分ですが、癖や好みを一般化するには短すぎます。
**レポート側で新しい癖・好み・価値観を断定しないでください。** それは profile.md 側の仕事です。

## レポートの構成

```
# Claude Code 週次レビュー <期間>

## 今週のサマリ（3〜5 行。摩擦と変化に限る）
## 数字（表。今週の値と、直前 4 週との比較）
## 今週の摩擦（中断・拒否・エラー・手戻りを、直前の文脈つきで）
## profile との照合（既存項目のうち今週も観測されたもの・食い違ったもの）
## 改善提案（2〜4 件。各項目に「根拠」と「やること」）
## 前回の観察ポイントの結果（初回は「初回のため省略」）
## 来週の観察ポイント（3 つまで）
```

## profile.md の更新方針

- 今週の観測を、既存項目の証拠と観測数に積み増す
- 既存のどれにも当たらない新しい傾向は「観察中」に新規追加する。いきなり「確定した傾向」に入れない
- 「観察中」の項目が 3 週 / 2 プロジェクトの基準を満たしたら「確定した傾向」へ移す
- 既存項目と食い違う観測があれば「変化・撤回した傾向」へ移し、経緯を書く
- 今週観測されなかった項目は消さない。観測行はそのままにする

## 長さ

レポートは 1200〜2500 字。網羅より、本人が来週の行動を変えられる指摘を優先します。
